# Android приложение, позволяющее скачивать музыку и воспроизводить ее на устройстве, используя deezer api и exoPlayer для вопроизведения

В этом проекте для выполнения запросов в сеть используются такие библиотеки как: Retrofit, OkHttp.
Для кэширования данных применяется Room, также выступая как single source of truth.
Инъекция зависимостей осуществляется, с помощью Dagger 2.
Проект разделяется на модули, а в роли архитектурного шаблона используется комбинация MVVM/MVI.
Навигация осуществляется, используя Jetpack Navigation, а построение view, через xml.

## Запуск
1. Склонируйте репозиторий: bash
git clone https://github.com/AndrewPyatunin/MusicPlayer.git

2. Откройте проект в Android Studio и запустите на устройстве или эмуляторе.
